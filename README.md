# Calculadora

Calculadora simple en JavaScript con las cuatro operaciones basicas: suma, resta, multiplicacion y division.

## Uso

```bash
npm install
npm start
```

## Pruebas

```bash
npm test
```

## Estructura

- `src/calculator.js` — logica de las operaciones.
- `index.js` — interfaz de linea de comandos.
- `tests/calculator.test.js` — pruebas unitarias con Jest.
- `.github/workflows/ci.yml` — integracion continua: ejecuta las pruebas en cada push y pull request.
